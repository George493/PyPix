PyPix - программа предназначенная для создания и редактирования пиксельной графики. После запуска программы вы сразу можете начать рисовать на холсте.
Программа предлагает различные инструменты для творчества, включая карандаш, заливку, линии, прямоугольники, эллипсы, пипетку и ластик. 
Если вы хотите изменить размер холста, вы можете выбрать из предустановленных размеров в выпадающем меню "Размер:".
Для увеличения или уменьшения масштаба используйте кнопки "+" и "-" или ползунок масштаба. Если вам нужно больше места для работы, нажмите "Полный экран".
Программа предоставляет небольшую палитру из 16 цветов, включая основные цвета, серые оттенки, пастельные тона, яркие неоновые цвета и классические пиксельные цвета.
Выбирайте основной цвет левой кнопкой мыши, а фоновый цвет - Shift+кликом по палитре. Для быстрой смены цветов местами нажмите кнопку "Поменять".
Когда вы ошибаетесь, используйте кнопки "Отменить (Z)" и "Повторить (Y)" для управления историей действий. Для очистки всего холста нажмите "Очистить (C)". Сетку на холсте можно включать и выключать кнопкой "Сетка".
Готовые работы сохраняйте в формате PNG, нажав "Сохранить (S)", а для загрузки существующих изображений используйте "Загрузить (L)". При сохранении откроется окно выбора папки и имени файла.
Программа поддерживает горячие клавиши для ускорения работы: 
Ctrl+Z - отменить действие
Ctrl+Y - повторить действие
Ctrl+S - сохранить изображение
Ctrl+L - загрузить изображение
C - очистить холст
G - переключить сетку
Пробел - поменять цвета местами
+/- - изменить масштаб
F11 - полноэкранный режим
